# libivcmp

Библиотека для сравнения кривых ВАХ. 

## Инструкция для Linux

1. Установите CMake:

   ```bash
   sudo apt update
   sudo apt install cmake build-essential
   ```

2. Создайте отдельную папку для сборки внутри проекта и перейдите в нее:

   ```bash
   mkdir build
   cd build
   ```

3. Сгенерируйте файлы конфигурации и соберите проект:

   ```bash
   cmake ..
   make
   ```

   В папке `build` появятся библиотека `libivcmp.so` и исполняемый файл `ivcmpexample` с примером.
4. Чтобы запустить пример, выполните команду (находясь в папке `build`):

   ```bash
   LD_LIBRARY_PATH=. ./ivcmpexample
   ```

## Инструкция для Windows

1. Для сборки под Windows понадобятся [CMake](https://cmake.org/download/), MinGW (или MSVC) и Redistributable Packages 2013. 
2. Для генерации файлов проекта откройте CMake GUI:
   * В поле "Where is the source code" укажите полный путь до корневой папки проекта `ivcmp`.
   * В поле "Where to build binaries" укажите путь до каталога, куда будут помещены файлы сборки. Рекомендуется использовать папку `build` внутри каталога проекта.
   * Нажмите кнопку "Configure". В появившемся окне выберите генератор в зависимости от вашего компилятора (MinGW Makefiles или вашу версию Visual Studio), затем нажмите "Finish".
   * После успешной конфигурации нажмите кнопку "Generate".
3. Далее выполните сборку в зависимости от выбранного генератора:
   * *Для Visual Studio 2013*
     * В интерфейсе CMake GUI нажмите кнопку "Open Project".
     * В открывшемся окне Visual Studio выберите конфигурацию (например, `Release`) и соберите проект через меню `Сборка -> Собрать решение` (`Build -> Build Solution`).
     * Готово. Исполняемый файл `ivcmpexample.exe`, а также библиотека `ivcmp.dll` и файл связи `ivcmp.lib` появятся в подпапке `Release` (или `Debug`).

   * *Для MinGW*
     * Откройте командную строку и перейдите в созданную директорию сборки:

       ```commandline
       cd путь/к/папке/build
       ```

     * Выполните сборку mingw:

       ```commandline
       mingw32-make
       ```

       (путь до mingw должен быть в системных путях)
     * Готово. Исполняемый файл `ivcmpexample.exe` и библиотека `ivcmp.dll` будут находиться в папке сборки.

## Сохранение промежуточных данных в файлы

В исходном коде библиотеки есть макроопределение `DEBUG_FILE_OUTPUT`. По умолчанию оно закомментировано. Если его раскомментировать, библиотека начнёт сохранять промежуточные состояния кривых и другую отладочную информацию в текстовые файлы. Для визуализации кривых в папке utils есть специальный скрипт.
